## 2026-06-05 - Missing Keyboard Accessibility on Custom Cards and Accordions
**Learning:** Custom interactive elements (like `div` tags used for clickable profile cards `EdCard` and accordion headers `CRow`) in this single-file React app lacked native keyboard focus (`tabIndex`), semantic roles (`role="button"`), keyboard event handlers (`onKeyDown`), and visual focus indicators (`:focus-visible`). This makes them inaccessible to users relying on keyboard navigation.
**Action:** When creating custom interactive elements instead of native `<button>` or `<a>` tags, always implement `role="button"`, `tabIndex={0}`, an `onKeyDown` handler (for Enter and Space keys), and clear `:focus-visible` styles in the CSS. Also remember to add `aria-expanded` to accordion headers and `aria-label` to icon-only buttons (like the `✕` delete button).
